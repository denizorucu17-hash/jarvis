# J.A.R.V.I.S.

Kişisel atölye asistanı. Yazılı ya da sesli: not, hava, döviz, haber, zamanlayıcı, kamera, uçuş ekranı ve tarayıcı.

Çipler: Atölye, Volt, Mira.

## Çalıştırma

```bash
npm install
npm run dev
```

Uygulama `http://127.0.0.1:8080` adresinde açılır.

Sohbet, ses ve web araması için `XAI_API_KEY` ortam değişkeni gerekir. Anahtar bu repoda yoktur.
